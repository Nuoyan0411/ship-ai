# Ship-AI 轮机工程故障智能诊断系统

## 1. 项目简介
Ship-AI 是一个面向船舶轮机工程场景的智能故障诊断助手。系统支持在线 AI 诊断与离线规则诊断双模式，能够根据用户描述的故障现象，提供专业的主机、辅机故障原因分析与排查建议，并支持对话记录与排查表的一键导出。

## 2. 10分钟极速复现指南
按照以下步骤，您可以在 10 分钟内完成本地环境的搭建与项目的启动运行。

### 2.1 环境准备
* **操作系统**：Windows / macOS / Linux
* **依赖软件**：已安装 Python 3.9 及以上版本，并配置好环境变量。
* **API 密钥**：如果您需要使用“在线 AI 诊断”模式，需要准备一个有效的 DeepSeek 或 OpenAI 等大模型的 API Key。
